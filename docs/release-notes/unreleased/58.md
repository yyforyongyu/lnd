# Bug Fixes

* [Invoice settlement finality](https://github.com/yyforyongyu/lnd/pull/58)
  fixes [issue #7463](https://github.com/lightningnetwork/lnd/issues/7463).
  Invoices remain accepted until their HTLC outcomes are final. The persisted
  pending-settle state requires operators to avoid downgrading while invoices
  remain pending. Recovery after a restart is best-effort: an interrupted
  finalization can leave an invoice pending (shown as `ACCEPTED` over RPC),
  requiring support-guided reconciliation.
