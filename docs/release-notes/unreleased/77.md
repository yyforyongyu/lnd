# Improvements

## RPC Updates

* [`NewAddress`](https://github.com/yyforyongyu/lnd/pull/77) allocates a fresh
  address for ordinary address types. On SQL wallets, `UNUSED_*` types reuse
  the oldest unused address in the selected account and branch. On kvdb
  wallets, every address type allocates the next address on each call.

* [`ListAccounts`](https://github.com/yyforyongyu/lnd/pull/77) includes the kvdb
  wallet's BIP44 account. Its address type is `UNKNOWN` because the RPC enum
  has no P2PKH value; its derivation path and public key remain available.

## Breaking Changes

* [`reset-wallet-transactions`](https://github.com/yyforyongyu/lnd/pull/77)
  replaces `dropwtxmgr`. It rewinds the wallet to its birthday for a full
  rescan, preserving keys, labels and transaction metadata. Disable the flag
  after a successful rescan to avoid repeating it on every restart.

* [`XCreateAccount`](https://github.com/yyforyongyu/lnd/pull/77) account names
  are unique within their key scope. If a custom name exists in multiple
  scopes, name-only spending requests reject that ambiguous name.

* [`FinalizePsbt`](https://github.com/yyforyongyu/lnd/pull/77) rejects unfinished
  wallet-owned inputs outside the requested account, even when the spent
  output is absent from the wallet's current UTXO set.

# Technical and Architectural Updates

## Code Health

* [The maintained btcwallet Wallet APIs](https://github.com/yyforyongyu/lnd/pull/77)
  now serve ordinary wallet operations through one Manager-owned Wallet per
  lnd instance, removing duplicate adapter operations. The integration also
  repairs native recovery setup, birthday rescans and address allocation;
  Task 470 continues to own full runtime parity.
